## 👨‍💻 Hakkımda

Yazılım geliştirme, backend mimarisi, veritabanı tasarımı ve iş süreçlerini dijitalleştiren uygulamalarla ilgileniyorum.

Karmaşık iş ihtiyaçlarını anlaşılır, sürdürülebilir ve kullanışlı yazılım çözümlerine dönüştürmeyi hedefliyorum.

- 🚀 **Üzerinde çalıştığım proje:** RasPel ERP
- 🧩 **İlgi alanlarım:** Backend geliştirme, veritabanı tasarımı ve yazılım mimarisi
- 💻 **Çalıştığım teknolojiler:** Java, Spring Boot, PostgreSQL, React ve Docker
- 🌱 **Gelişim hedefim:** Daha iyi mimariler tasarlamak ve kaliteli yazılım ürünleri geliştirmek
- 🎯 **Amacım:** Gerçek problemlere çözüm sunan, bakımı kolay ve ölçeklenebilir uygulamalar geliştirmek
